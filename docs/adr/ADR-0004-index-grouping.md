# ADR-0004 — 首頁索引二級結構＋註冊表 group 欄（Q7 使用者鎖定，2026-09-07）

本工作區第一份 ADR（Q0–R3 的決策記錄在 .scratch/ 的 DECISIONS 檔；本檔起，難以逆轉的架構決定進 docs/adr/）。

## 決定
1. `courses.yml` 註冊表每門課加 `group` 欄；分組＝診所業務分類鏡射：`thread-lift`（埋線區）／`collagen-stimulator`（膠原增生劑區）／`demo`（演示區，不佔業務類）。
2. 渲染層採 TryHackMe 式二級：首頁大類區塊→展開課程清單；視覺語言沿用 Q2 鎖定的 Joseph Berry Masterclass 基線。
3. M10 擴充斷言升級：新課＝JSON 一檔＋註冊表一行（含 group），大類區塊自動長出——分組結構不得手寫 HTML。

## 理由（四刀合一）
- Feynman 釘：註冊表層三案同價，手寫分隔條＝第一次違反自家擴充斷言。
- Naval：真正變數是「一年後幾門課」——生意在長，結構要裝得下。
- Taleb：三選項中唯 TryHackMe 式不用預測未來＝最便宜的選擇權。
- Jobs：分組＝診所掛在門口的菜單分類，不是 UI 審美題。

## 後果
- 渲染層寫分組渲染；既有六門課 JSON 零改（分組資訊只在註冊表）。
- 測試表長一期：分組渲染斷言（雙殼同表）。

## 往後要做（三根釘——出自本跑三把尺，寫入即離唇，落地要有 commit hash）
1. 殭屍課斷言可重跑：M15 升級為自造一門假課（註冊表加假 group 行＋最小 JSON），渲染後驗它落進正確區塊，跑完拆掉還原——可重複執行，不依賴第七門課本人到場。（出處：Taleb）
2. 殭屍課跑在 tmp 副本＋自起臨時 port server 生命週期——真註冊表零 byte 動，保「工作區乾淨＝憑據」鏈；port 自起自關，跑完還原。（出處：Elon）
3. teardown 開場先掃殘骸：斷言啟動前先清上一跑可能留下的殭屍殘骸再種新的——crash-proof，綠燈不撿上一次的上屍。（出處：Feynman）
